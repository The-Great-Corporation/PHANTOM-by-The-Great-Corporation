## 🎮 Prise en Main en 3 Minutes

### 1. Sur votre PC Windows
1. Double-cliquez sur le raccourci **« PHANTOM Server TGC »** sur votre Bureau (ou lancez `Lancer_Serveur_Phantom_TGC.bat`).
2. Cliquez sur le bouton central **« DÉMARRER LE SERVEUR PHANTOM »**.
3. Votre PC est prêt et écoute les connexions.

### 2. Sur votre Smartphone Android
1. Ouvrez l'application **PHANTOM**.
2. Votre PC est détecté automatiquement sur votre réseau Wi-Fi local : le voyant passe au vert.
3. Touchez **▶ JOUER**.

Votre smartphone se transforme instantanément en une manette haute précision. Lancez votre jeu préféré sur Steam, Xbox Game Pass ou émulateur : il reconnaît immédiatement votre contrôleur.

## ⚡ Astuces Pro en Cours de Jeu

* **Accéder aux Réglages Rapides** : Glissez le doigt depuis la bordure gauche pour ouvrir le *Quick Settings Drawer*. Vous pouvez changer de mode de stick (flottant ou fixe) ou ajuster la sensibilité sans quitter la partie.
* **Personnaliser l'Apparence** : Rendez-vous dans le *Studio de Configuration* sur l'écran d'accueil pour appliquer vos skins favoris (Xbox, PlayStation, Nintendo, Cyberpunk, Ghost) ou importer vos propres GIFs animés.
* **Mode Sans Latence (USB)** : Branchez votre téléphone en câble USB avec le Débogage USB activé pour une latence nulle (0 ms).
