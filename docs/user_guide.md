# PHANTOM User Guide

Welcome to the PHANTOM gamepad emulator.

## Overview
PHANTOM allows you to use your mobile device as a virtual gamepad for this computer.

## Connection
1. Ensure your smartphone is connected to the same Wi-Fi network as this computer.
2. Open the Phantom mobile app.
3. If auto-discovery is active, the app will connect automatically.
4. Otherwise, enter the IP address shown in the Dashboard.

## Troubleshooting
- Make sure the PHANTOM server is started (click the "START PHANTOM SERVER" button).
- Check your firewall settings.
